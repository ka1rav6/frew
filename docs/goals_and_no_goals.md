# Frew 

I plan to make a really good combined interface for machine learning in C++. But, note that this 
is not for production purposes, and more for learning and understanding purposes

## GOALS

With this, I hope to teach you and make you understand:
- How a tensor is implemented in tensor libraries
- Modern C++ with Makefile
- Machine Learning algorithms in detail
- Metrics of ML evaluation
- Data cleaning and scaling
- Using some C concepts (like macros) in your code
- Creating a unified API for tensor libraries, CSV parsing libraries, and ML libraries
- Managing big projects hands on
- How to create libraries and software in general (unit tests, logging, and documentation)
- Making it very easy for you to understand every piece of code and go through this codebase with ease

## NO GOALS

- SIMD/ GPU programming
- Advanced Neural Networks/Deep learning
- Multithreaded/multiprocess programming

## Prerequisites:

- Decent Modern C++
- Basic linear algebra and probability statistics
- An overall idea of Calculus concepts like `gradients` (though I will go into it in detail)

**NOTE:** You do not need to know ML for this. That is what I am here for:)

## Who is this for?
- People who are genuinely interested in knowing how ML systems (numpy, pandas, scikitlearn) work
- People wanting to learn advanced C++ programming
- People wanting to become better Low Level Software Developers/better programmers
- People interested in the math behind ML
- People who ask the question *"How was this implemented internally?"*


## My Coding Methodology

I believe AI is a very good summarizer and teacher. I still use documentation a lot but
I will not refrain from using AI if it is to understand a concept or a function, yet I will not use 
generative AI for code generation. All the code I write is for you guys and I may commit mistakes too 
but I will make sure I make you understand each thing all the way.

This project is for mine and your educational purposes only
